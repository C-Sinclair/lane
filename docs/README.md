# docs

Three kinds of document, kept separate because they change differently:

- [`design/`](design/README.md) — how a subsystem works today. Rewritten in place.
- [`decisions/`](decisions/README.md) — one choice each, with context and consequences.
  Historical and append-only; a reversed decision is superseded, never edited away.
- [`friction/`](friction/README.md) — a flat, append-only log of things that got in the way,
  how they were resolved, and what they informed.

Start at whichever index matches what you're looking for; each explains its own numbering
and update rules.
